# Web Dev NC Homebrew Tap

Official Homebrew tap for [Eye Saver](https://eyesaver.webdevnc.com/) and applications by Web Dev NC.

## Installation

### Eye Saver Desktop (macOS)

Install via Homebrew:

```bash
brew install --cask thenjk57/tap/eye-saver
```

Or tap the repository first:

```bash
brew tap thenjk57/tap
brew install --cask eye-saver
```

### Updating

To update Eye Saver to the latest version:

```bash
brew upgrade --cask eye-saver
```

### Uninstalling

```bash
brew uninstall --cask eye-saver
```
